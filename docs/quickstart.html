Quick start快速开始

From zero to a benchmark in one command一条命令跑起第一个基准

The default mode is scenario: N users holding independent conversations that grow turn by turn. You need a running OpenAI-compatible endpoint and a tokenizer directory.默认模式是 scenario：N 个用户各自进行不断增长的多轮会话。只需要一个正在运行的 OpenAI 兼容端点和一个 tokenizer 目录。

Install安装

shell
# pip (the extras pull in the agent, record/replay and mock-server bits)
pip install "clawperf[agent,record,replay,mock-server]"

# or the container image — it bundles examples/ and a local tokenizer
docker pull ghcr.io/ucm-system/clawperf:latest

First run首次运行

bash
clawperf --mode scenario \
  --endpoint http://localhost:8000/v1 \
  --model Qwen3-0.6B \
  --tokenizer /mnt/model/Qwen3-0.6B \
  --context-profile medium \
  --num-users 8 --max-turns 20 \
  --metrics-endpoint http://localhost:8000/metrics \
  --output results.json

Point --tokenizer at a local directory. It is loaded strictly offline (no hub lookup, no download) and drives exact token counting, context clamping and content generation. Use the same directory your server loaded the model from — or the image's bundled /app/tokenizers/qwen3-0.6b to sanity-check the setup.把 --tokenizer 指向本地目录。它会严格离线加载（不查 hub、不下载），并负责精确分词、上下文裁剪与内容生成。指向服务端加载模型的同一个目录即可 —— 也可以先用镜像内置的 /app/tokenizers/qwen3-0.6b 验证环境。

The four numbers that matter四个关键数字

TTFT — time to first token. TPOT — per output token. E2E — full request latency. Hit rate — read from the server's Prometheus counters, never inferred.TTFT —— 首 token 时延。TPOT —— 每输出 token。E2E —— 请求端到端时延。命中率 —— 直接读服务端 Prometheus 计数器，从不推断。

Two artifacts per run每次运行两个产物

results.json (config + per-user/per-turn detail + metrics) and results.md (verdict, findings, ASCII charts). Regenerate the report with clawperf report results.json.results.json（配置 + 按用户/按轮明细 + 指标）与 results.md（结论、发现、ASCII 图表）。可用 clawperf report results.json 重新生成报告。

No GPU at hand?手边没有 GPU？

Ship the mock server instead: it has a real trie prefix cache and vLLM-style /metrics, so every mode works end to end.用内置 mock server 替代：它带真实的字典树前缀缓存与 vLLM 风格 /metrics，所有模式都能跑通。

bash
# terminal 1
clawperf-mock-server --port 8000

# terminal 2 — the same command, now pointed at the mock
clawperf --mode scenario --endpoint http://localhost:8000/v1 \
  --model qwen3-0.6b --tokenizer tokenizers/qwen3-0.6b \
  --context-profile fresh --num-users 4 --max-turns 4 \
  --metrics-endpoint http://localhost:8000/metrics --reset-cache

Exit codes & troubleshooting退出码与故障排查

Code退出码Meaning含义
0the benchmark ran; results written基准跑完并写出结果
1configuration or pre-flight error (no benchmark ran)配置或预检错误（未开始跑基准）
2the benchmark ran but every request failed (CI gate)基准跑了但全部请求失败（CI 门禁）
3interrupted (Ctrl+C); partial results are written被中断（Ctrl+C）；退出前会写出部分结果
