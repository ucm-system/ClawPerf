--kv-bytes-per-token <KV_BYTES_PER_TOKEN>2.0Bytes per KV cache token, for GB↔token conversion. Varies by model (e.g. DeepSeek MLA ~0.5, Qwen2.5 72B ~4.0).每个 KV 缓存 token 占用的字节数，用于 GB↔token 换算。不同模型差异很大（如 DeepSeek MLA 约 0.5，Qwen2.5 72B 约 4.0）。
